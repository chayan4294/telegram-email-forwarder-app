# 📱 Telegram Email Forwarder - Android App

Native Android Application to forward Gmail incoming emails to a Telegram group in real-time (1s interval) via 24/7 background Foreground Service.

## ✨ Features
- 🔘 **One-Touch ON/OFF Switch**: Toggle background email forwarding instantly.
- ⚡ **Super-Fast (1-Second Check)**: Checks Gmail IMAP SSL every second.
- 🔒 **Foreground Service with Sticky Notification**: Android OS won't kill it even when screen is locked.
- 📎 **Full Attachment Support**: PDFs, images, DOCX, ZIP files forwarded directly.
- 📝 **Live Activity Log**: Watch forwarded emails and status right on your screen.
- 🔋 **Battery Optimization Bypass**: Built-in 1-tap shortcut to disable Android background killing.

## 🚀 How to Download the APK (Free GitHub Auto-Build)
1. Push this folder to your GitHub account (as a new repository).
2. Go to the **Actions** tab on your GitHub repository.
3. The **Build Android APK** workflow will run automatically (takes ~2 minutes).
4. Click on the completed workflow run and download **Telegram-Email-Forwarder-APK** (`.zip`).
5. Extract and install `app-debug.apk` on your phone!
